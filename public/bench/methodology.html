METHODOLOGY AND LIMITATIONS

Claims earn their way onto the page.

The same task and agent are evaluated with Focusa and without Focusa. Public claims remain blocked until redaction, secret scanning, scoring, and immutable evidence checks pass.

Comparison contract

Primary comparison: full_focusa versus no_focusa. Public results identify task suite, model/version, pricing snapshot, scoring commit, environment digest, run IDs, and raw ledger hash.

What remains private

Raw prompts, private holdout bodies, transcripts, token payloads, private file contents, sensitive diagnostics, and unredacted paths are never served by this static surface.

Failure policy

Regressions stay visible. A failure card can move to promoted only after an explicit improvement candidate, linked work, before/after rerun, and evidence-backed promotion decision.

Current limitation

No public-safe measured run is included in this preview. Therefore every performance metric renders as “Not measured,” and no uplift claim is made.
