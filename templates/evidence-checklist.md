# Evidence Checklist

- [ ] Test output captured
- [ ] Git diff reviewed
- [ ] File paths listed
- [ ] API response captured
- [ ] Screenshot/log attached if relevant
- [ ] Workpoint evidence linked
- [ ] Resume packet confirms evidence visibility

## Link evidence

```bash
focusa workpoint evidence-link \
  --target-ref "<file-or-endpoint>" \
  --result "<bounded proof summary>" \
  --evidence-ref "<stable path, URL, run id, or artifact>"
```
