focusa audit CLI timeout fix — 2026-07-06

## Problem
`focusa audit` returned:
  Error: [API_TIMEOUT] url=http://127.0.0.1:8787/v1/events/recent?limit=50 reason=error sending request for url

## Root cause
crates/focusa-cli/src/api_client.rs:13
  const DEFAULT_TIMEOUT_SECS: u64 = 2;

The CLI HTTP client defaulted to a 2s request timeout. With 518,860 rows in the
`events` table on a real user's daemon, `SELECT ts, payload_json FROM events
ORDER BY ts DESC LIMIT 50` takes longer than 2s on cold caches.

## Fix
- Bumped `DEFAULT_TIMEOUT_SECS` from 2 → 10 in `api_client.rs`.
- Override available via `FOCUSA_API_TIMEOUT` env var.
- Query already uses `idx_events_ts` B-tree index (verified via EXPLAIN QUERY PLAN).
- Fix applies to ALL CLI commands (every command funnels through `ApiClient`).

## Proof
