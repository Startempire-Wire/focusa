# Focusa Operator World Model composition contract

**Contract version:** 0.1.0  
**Date:** November 19, 2026

## Purpose

Focusa supplies governed cognitive primitives that an operating agent can compose into an Operator World Model. Focusa is not the owner’s complete world database and does not create operator authority.

## Primitive families

The composition surface includes canonical awareness, Focus State, context cognition, Mission Canvas, trajectories, Workpoints, temporal authority, predictions and calibration, evidence lineage, metacognition, resource mode, graph traversal, turns, work rails, and work loops.

Each projection must expose scope, source lineage, freshness, confidence or authority posture, and whether it is canonical, advisory, degraded, or defective. An agent must be able to preserve a blind spot rather than fabricate a replacement.

## Composition rules

1. New operator words outrank a conflicting projection.
2. A verified RemoteWorkspaceBinding must remain attached to its repository, remote root, continuity, trajectory, and Workpoint.
3. Session identity is temporal metadata and cannot replace project continuity.
4. Prediction is advisory until an owning authority confirms it.
5. Evidence linkage and post-action evaluation are required for learning.
6. Metacognition may adjust confidence and strategy but cannot widen authority.
7. Focusa defects must be reported as defects, not converted into false operator uncertainty.

## Expression package boundary

Focusa exposes cognition and execution primitives through its own licenses and permissions. Wirebot package levels may add pre-integrated behavior without confiscating independently purchased Focusa rights. Proto does not provision Wirebot automations, alarms, or workforces. Tempo adds packaged routines and alarms. Crew adds bounded workforce composition and dispatch. Chief adds persistent owner-wide coordination. Sovereign adds the contracted full-SOVOS owner environment. Focusa must report the source of each admitted right so the installer and runtime do not confuse independent Focusa capability with a higher Wirebot model.
