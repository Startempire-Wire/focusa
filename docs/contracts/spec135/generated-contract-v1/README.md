# Spec 135 generated-contract bundle

`openapi-3.0.3.json` is the deterministic transport snapshot exported from the
canonical Focusa Agent Operation Registry. It uses OpenAPI 3.0.3 and records
JSON Schema 2020-12 as `x-focusa-json-schema-dialect`.

Generated clients consume this file; handwritten duplicate operation or DTO
authority is forbidden. Other foundation-owned members include the JSON Schema
bundle, Operation Registry/action bindings, compatibility handshake fixtures,
A2UI catalog, and UI capability snapshot.

`uiai.focusa_ui_eval_scenario.v1.schema.json` and
`uiai.focusa_ui_eval_result.v1.schema.json` are the external UIAI Engine Eval
boundary. The Alpha 0 scenario/result fixtures retain bounded browser session,
screenshot, diagnostics, accessibility, Focusa Evidence, and recovery refs;
UIAI Engine remains the browser execution owner.
