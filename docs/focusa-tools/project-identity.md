# Project Identity tools

ProjectIdentity tools verify the active project folder before project-bound Workpoint, Trajectory, evidence, or carryover context is trusted as canonical.

Navigation metaphor: project identity is the vessel/hull for guidance. Better project-root confidence improves navigation reliability, but Trajectory still defines the functional route and destination.

- [`focusa_project_identity`](tools/focusa_project_identity.md) — resolve marker/git/beads/workspace/cwd/daemon/operator signals.
- [`focusa_project_verify`](tools/focusa_project_verify.md) — compare expected identity fields and surface scope mismatches.
