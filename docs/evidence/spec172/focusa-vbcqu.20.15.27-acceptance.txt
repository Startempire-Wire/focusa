Bounded result
- Menubar and TUI are presenters, not products (Spec 172 §15): both carry the
  frozen presenter-not-product sentence; neither owns pricing, grants,
  limits, or commercial policy; no local commercial table exists in either
  presenter (pure functions, no module-level mutable state).
- License Type display is canonical and fail-closed: the frozen
  code->label fixture is byte-identical across the menubar module, the TUI
  presenter, and the action map `spec172` section; an unknown or
  caller-supplied License Type code never projects (a presenter never mints a
  License Type); product grants are filtered to the exact canonical products
  (`focusa`, `uiai_engine`) with duplicates dropped.
- Operator/Bundle upgrade accuracy: an upgrade is displayed ONLY when the
  daemon presenter vocabulary signals one (select_purchase /
  open_checkout / activate_or_manage_entitlement); verified no-license
  shows "Operator upgrade available"; an actively granted Operator/UIAI/
  Bundle License Type shows "Manage entitlement" and is never re-sold as an
  Operator upgrade (Spec 172 §10.3); offline-grace with a granted type is
  managed, not re-sold.
- Retained read/export/recovery controls and locked-state fixtures: the
  frozen 9-entry always-reachable set (navigation, status, account, read,
  export, recovery, repair, update, uninstall) is byte-identical across the
  menubar module, the TUI presenter, and the action map; locked-state
  fixtures name the canonical upgrade/recovery action
  (activate_or_manage_entitlement) and never disable read, export, recovery,
  repair, update, or uninstall (Spec 172 §5.3/§6.2).
- Node semantics: one verified operator seat, up to three registered
  operator nodes; CLI, TUI, Pi, menubar, Focusa Desktop, and Cockpit clients
  on the same node do not consume separate nodes (Spec 172 §7.3); neither
  presenter counts apps as nodes and no per-app node counter exists.
- Fail-closed rules hold in every replayed posture: no caller-controlled
  product, price, License Type, family, feature, limit, node, or commercial
  right is accepted; no raw email, key, token, customer row, credential, or
  card data exists in any fixture; no implicit legacy Download 453 mapping;
  no data deletion or blocked basic export, repair, rollback, stable security
  update, or uninstall.
