- Added the canonical Spec 172 presenter projection

  capability family, denial, retained access, and upgrade/recovery action
  from the authority snapshot only, through the core license guard
  (`focusa_license::resolve_license_guard`). The CLI never accepts a
  caller-selected product, price, License Type, family, feature, limit, node,
  or commercial right; preflight `--family` remains bounded to the six
  canonical families and unknown families fail closed
  (`E_AUTHORITY_UNKNOWN_PREFLIGHT_FAMILY`). Preflight keeps its nonzero exit
  semantics for denied/limited gates.
- Posture is derived only from the snapshot state (active_paid_operator,
  offline_grace, unverified, refunded_or_revoked, missing_or_corrupt);
  `verified_no_license` is canonical vocabulary that a presenter never
  synthesizes. License Type is the frozen registry code for the snapshot's
  own product (focusa_operator_lifetime_v1 / uiai_operator_lifetime_v1) or
  `none`; the composite Bundle SKU remains a commerce SKU in the frozen
  vocabulary, never a third feature catalog. Denials use only the frozen
  Spec 172 §21 stable errors (EMAIL_VERIFICATION_REQUIRED, VERIFIED_LIMITED_ACCESS,
  LICENSE_TYPE_REQUIRED, PRODUCT_NOT_INCLUDED, CAPABILITY_FAMILY_NOT_INCLUDED,
  ENTITLEMENT_POLICY_UNKNOWN, RECOVERY_ONLY, ...). Retained access
  (navigation, status, account, read, export, recovery, repair, update,
  uninstall) and upgrade/recovery actions are frozen presentation vocabulary;
  every denial preserves retained access.

  (`projectSpec172PresenterV1(toolName, posture)`): family comes from the
  canonical tool contract, posture from the daemon authority, product and
  License Type from frozen surface vocabulary — the function signature
