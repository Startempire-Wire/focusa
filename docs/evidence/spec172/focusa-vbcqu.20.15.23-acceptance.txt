Bounded result
- Added `DynamicOperationManifest` (operation_id, product_owner,
  operation_class, capability_family, side_effect_class, signed,
  declared_policy_fields) and `verify_dynamic_operation_manifest()`: a
  fail-closed verifier for operation registry runtime intake. Unsigned
  manifests, unknown operations, unknown owners, unknown mutation classes,
  unknown side effects, and unregistered families all quarantine before
  execution. A tool cannot self-label as `recovery` to bypass licensing
  (`QuarantinedSelfLabeledRecovery`); any claim that differs from the
  canonical registry, or any declared client policy field (product, price,
  License Type, family, feature, limit, node, commercial right), quarantines
  as client-selected policy. Trusted operations inherit canonical policy;
  they never become limited/paid by client metadata.
- Added `ManifestQuarantineLedger` + `QuarantinedManifestRecord`: rejected
  dynamic manifests and UI bindings are recorded with monotonic sequence and
  the stable Spec 172 Section 21 error `ENTITLEMENT_POLICY_UNKNOWN`;
  quarantine is checked before execution so a quarantined operation can never
  run even if a later manifest looks canonical.
- Added `verify_generated_ui_action()`: generated UI may render only canonical
  registered actions; a signed binding outside the canonical registered action
  set quarantines as grant expansion (`QuarantinedGeneratedUiGrantExpansion`),
  and unsigned bindings quarantine. Verified against the 108 canonical
  ui-action-bindings.fixture.json actions (every one maps to a registry
  operation with `allowed_in_generated_ui == true`, exactly equal sets), and
  the a2ui-catalog.json presenter catalog carries zero commercial policy
  fields (no presenter-owned policy).
- Operation registry runtime intake now stamps trusted metadata on all 108
  canonical operations: `product_owner: focusa` and a canonical
  `side_effect_class` (`none` for reads, `remote` for device pairing,
  `local` otherwise), alongside the existing operation_class,
  capability_family, and spec172_family fields. The generated OpenAPI
  `x-focusa` projection carries the same two fields. Regeneration is
  deterministic (`generated_at` preserved) and `--check` passes.
- 12 adversarial fixtures all fail closed: unsigned, unknown operation,
  unknown owner, unknown mutation class, unknown side effect, unregistered
  family, self-labeled recovery, declared License Type, declared
  product+price, mutation reclassified as read, future product, and
  generated-UI grant expansion.
