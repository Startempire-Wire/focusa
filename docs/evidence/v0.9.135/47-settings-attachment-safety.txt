Observed: 2026-07-27

Root cause:
- SettingsList.onChange runs after the command AsyncLocalStorage attachment context
- persistDraft called context-dependent getAttachmentRuntime() with no key
- the exception escaped the deferred UI callback and terminated Pi

Fix:
- capture currentAttachmentKey and its runtime at command entry
- every deferred settings callback uses the captured runtime explicitly
- settings refuse to open when scoped attachment authority is absent
- persistence is exception-contained and reports that the prior configuration remains active
- draft and OTA values restore prior state when persistence fails
- settings never call unkeyed getAttachmentRuntime() from deferred callbacks
