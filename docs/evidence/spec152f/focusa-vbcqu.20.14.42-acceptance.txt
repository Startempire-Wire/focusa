Bounded result
- Added the typed denial/purchase/recovery UX contract
  (crates/focusa-license/src/denial_ux.rs). DenialUxErrorCode is a closed
  enum of the 10 stable error codes (ENTITLEMENT_BASE_REQUIRED,
  ENTITLEMENT_FEATURE_REQUIRED, ENTITLEMENT_REQUIRED,
  ENTITLEMENT_LIMIT_EXHAUSTED, ENTITLEMENT_RECOVERY_ONLY,
  ENTITLEMENT_SNAPSHOT_MISSING, ENTITLEMENT_ROUTE_UNCLASSIFIED,
  ENTITLEMENT_POLICY_UNKNOWN, ENTITLEMENT_RESERVATION_FAILED,
  ENTITLEMENT_IDEMPOTENCY_REQUIRED) with fail-closed label lookup;
  DenialUxErrorSpec carries http status, retryable flag, plain-language
  public message, one safe next action, its label, and a stable link.
  DenialUxMessage derives the canonical grid message via
  denial_ux_message_for(state, family) from the authority reducer
  (reduce_entitlement_state) and denial_ux_message_for_code(code); unknown
  codes, states, families, and links fail closed (never rendered). Every
  message lists the frozen 9-entry retained-access set (navigation, status,
  account, read, export, recovery, repair, update, uninstall) and exactly one
  safe next action; preserves_route() proves every gated message keeps a
  route to purchase or recovery.
- Committed the cross-presenter message catalog
  (docs/contracts/spec152f-denial-ux-catalog.v1.json, schema
  focusa.spec152f.denial_ux_catalog.v1): 63 state/family cells, each with a
  plain-language blocked action, reason, retained access, one safe next
  action, and a link; the 10-entry stable error registry; the four stable
  links; the frozen 9-entry always-reachable set; 7 public-message rules; and
  presenter bindings for CLI, desktop/menubar, TUI, Pi/agent, and branded
  facades. The Rust contract embeds the artifact bytes
  (DENIAL_UX_CATALOG_JSON / embedded_denial_ux_catalog) and its unit tests
  prove the typed derivation is identical to the artifact for all 63 cells.
- Added the JS message fixture
  (public/activation/focusa-denial-ux-catalog.mjs): projectDenialUxMessage
  and messageForErrorCode return the canonical message and reject spoofed
  input (unknown state/family/code, grid+code ambiguity, raw identities,
  grants, prices, absolute redirect links, query-bearing links) by returning
  null; denialUxLink resolves only the four stable relative paths.
- No internal route/lease details, no false urgency, no account enumeration,
  no raw email/key/token, and no dead-end paywalls: enforced by the generator
  self-check and by the parity test's forbidden-substring/word scan over every
  customer-facing message field. Account recovery, read, customer-data
  export, repair, stable security update, rollback, and uninstall allowances
  are never disabled by the catalog (all retained in every message).
- No local/self-issued Evaluation; no caller-controlled product/price/grants;
  no presenter-owned commercial decision; no raw keys/tokens/customer PII in
  code, tests, or evidence; no 395 independent paywalls (one registry);
  customer data export, account control, repair, stable security update,
  rollback, and uninstall allowances untouched.
