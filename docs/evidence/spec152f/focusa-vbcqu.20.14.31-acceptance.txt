- Reclassified activation/recovery pairing routes from TeamRemote premium to
  BaseFocusa: /connect/firstrun, /v1/connect/room/firstrun,
  /v1/device/pair/start (activation pairing), /v1/device/pair/revoke
  (recovery). These operations are now reachable without a premium grant and
  use the BaseFocusa family with no limit bucket, so they are available to
  VerifiedNoLicense users (limited) and ActivePaid users (base).
- Reclassified read-only device/connect status routes from TeamRemote premium
  to BaseFocusa (core.evidence): /v1/device/pair/list (read-only),
  /v1/device/pair/status (read-only, also recovery), /v1/connect/rooms
  (read-only), /v1/connect/status (read-only), /v1/connect/room/{room_id}/status
  (read-only). These are now classified as evidence/read operations with no
  limit bucket.
- Reclassified /v1/project/session-transfer from BaseFocusa (core.mission) to
  TeamRemote premium (team.multi_operator) with team_operators limit bucket.
  Session transfer between peers now requires the premium grant.
- Additional peers/operators/remote collaboration routes remain premium:
  /connect, /connect/{room_id}, /connect/room/{room_id}/scan,
  /v1/connect/approve, /v1/connect/room/create, /v1/connect/room/start,
  /v1/connect/room/{room_id}/approve, /v1/connect/room/{room_id}/join,
  /v1/connect/room/{room_id}/mac-offer, /v1/connect/start,
  /v1/device/pair/complete (all require team.multi_operator).
  All sync and instances routes remain premium (require remote.stream).
- Token management routes (/v1/tokens/*) remain BaseFocusa — API token
  management is core functionality, not team expansion.
- Node management routes (lineage) remain BaseFocusa (core.evidence) — base
  node management is not premium.
