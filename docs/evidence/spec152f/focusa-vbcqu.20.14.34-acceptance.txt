  returns PremiumFamilyDecision::Feature or PremiumFamilyDecision::Denied.

  additive premium packaging feature; basic export is never blocked.

  export command (crates/focusa-cli/src/commands/export.rs). Basic customer-data
  export (JSONL, Parquet) is now always available to authenticated customers.
- Updated the license doctor reference from "commercial_export" to
  "focusa.export.packaged" with evidence pointing to
  crates/focusa-core/src/license.rs:require_export_packaged.
- Exported SecurityPrerequisite from focusa-license for external test use.
- Updated spec152f_automation_entitlement and spec152f_release_proof_entitlement
  tests: CustomerDataExport now carries a premium feature, so the
  non-premium-families-empty assertion excludes it with an explanatory comment.
- No caller-controlled product, price, grant, or feature input is accepted.
  Basic export works in every blocked entitlement state; premium denial
  affects only clearly additive packaging.
