Bounded result
- Durable node identity is created once per config directory
  (`load_or_create_node_identity`) with schema `focusa.node_identity.v1`,
  random v7 node id, and product binding, persisted atomically
  (`atomic_private_write`: temp file + rename, 0600 on unix) and validated
  fail-closed on read (schema/product/uuid shape; corrupt files yield
  `NodeIdentityInvalid`, never a regenerated or downgraded identity).
- OS-protected refresh credential storage: `KeyringCredentialStore` wraps the
  `keyring` crate (macOS Keychain, Linux Secret Service, Windows Credential
  Manager) behind the `ProtectedCredentialStore` trait (put/get/delete).
  `protected_store_backend_for_os` maps the three supported platforms and
  returns the typed `CredentialStoreError::StoreUnavailable` posture for any
  unknown OS; native store failures map to typed unavailable/missing/write/
  delete postures, never a plaintext fallback.
- Credential rotation/removal: `rotate_refresh_credential` writes then re-reads
  to verify persistence and returns a `CredentialRotationReceipt` carrying
  `secret_persisted_in_receipt: false` and only service/account/backend/timing
  metadata. `delete` removes the credential; missing entries map to
  `CredentialMissing`.
- `PersistedAuthorityState::from_verified_envelopes` (decodes the signed key
  set, derives sequence, verifies the lease, persists `refresh_after: None`)
  and `write_atomic` (create-new temp file, 0600 on unix, sync, rename) add
  durable atomic authority-state writes; the new `AuthorityStoreError::Write`
  variant resolves to `authority_state_unwritable`, fail-closed.
- Secrets never leave the protected boundary: `SensitiveCredential` redacts
  Debug/Display (`[REDACTED]`), handles carry identity only
  (`focusa.<product>.license-authority` / `node:<node_id>:refresh`), and the
  rotation receipt cannot contain the secret. No raw refresh token appears in
  JSON, argv, env output, logs, receipts, or fallback plaintext (Spec 158
  implementation remains excluded; licensing permits capability but never
  selects or creates cognitive/Workstream authority).
