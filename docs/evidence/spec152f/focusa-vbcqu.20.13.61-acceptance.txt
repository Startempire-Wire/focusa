Bounded result
- Added tests/spec152e_lifecycle_outage_e2e_test.py: a build-independent,
  offline, deterministic end-to-end journey over every named surface on one
  sqlite kernel (fixed clock, synthetic EDD fixture tables, frozen contracts
  loaded read-only). The php harness runs twice and its stdout is byte-identical
  (replayable from the pinned commit); every positive/negative check is counted.
- Node limit: three concurrent registrations settle within the limit (atomic
  reservation + settlement, write-locked counter 3/3); the fourth fails closed
  with NODE_LIMIT_EXHAUSTED and creates no node or reservation row; explicit
  deactivation releases the slot exactly once and the freed slot is reused
  through the explicit reserve/settle flow; a malformed device key fails closed
  before any reservation.
- Signed lease issuance and refresh rotation: lease issued at server sequence 12,
  refresh rotates to a strictly monotonic sequence 13 chained to the exact prior
  payload digest, old lease settles superseded/refresh_rotated, rotation
  journals lease_superseded + lease_issued outbox events and re-seeds a one-time
  credential (digest at rest).
- EDD lifecycle terminal matrix: refund, chargeback (Stripe dispute), revoke,
  expiry, and subscription cancel each project to the exact EDD license state
  (refunded/revoked/expired/cancelled) with recovery_only refresh posture and a
  monotonic sequence increment; each refresh is denied with a SIGNED
  recovery-only refusal (REFUNDED / REFUNDED / REVOKED / EXPIRED / CANCELLED)
  whose envelope independently verifies (verifyRefusal); the leases settle
  refunded/edd_refunded, revoked/edd_revoked, superseded/stale_sequence.
  Refund redelivery journals as replayed with no sequence bump; a completed
  order can never reactivate a refunded license (LICENSE_TERMINAL_REACTIVATION_DENIED);
  an out-of-order authority ordinal can never roll the sequence back
  (ENTITLEMENT_SEQUENCE_ROLLBACK_DENIED); revocation carries a durable audit
  (license_revoked + lease_revoked outbox events retained with the projection
  history); unknown statuses, raw email, client-controlled price, mismatched
  customers, and terminal events without prior entitlement truth all fail closed
  (EDD_STATUS_UNKNOWN / INPUT_RAW_EMAIL_FORBIDDEN / CLIENT_COMMERCIAL_FIELDS_FORBIDDEN
  / EDD_CUSTOMER_RESOLUTION_FAILED / ENTITLEMENT_REQUIRED).
- Stale sequence/software: after upgrade + suspend, a client presenting the old
  lease is denied refresh with a signed STALE_SEQUENCE recovery-only refusal and
  the lease settles superseded/stale_sequence; client-side envelope verification
  rejects the stale envelope (STALE_SEQUENCE) and a wrong node (WRONG_NODE).
- Missed callback + reconciler: canonical EDD license revoked with no projection
  and no outbox event (the hook never fired) is repaired by the reconciler — the
  terminal projection is applied, the signed license_revoked outbox event is
  appended, the run converges (second apply repairs nothing), the authority
  sequence advances strictly monotonically, and stale access can no longer
  refresh (signed REVOKED recovery-only refusal). Canonical EDD revoke truth is
  preserved untouched; unknown modes/scopes and client commerce fields fail
  closed (RECONCILIATION_MODE_UNKNOWN / RECONCILIATION_SCOPE_UNKNOWN /
  CLIENT_COMMERCIAL_FIELDS_FORBIDDEN).
- Outbox: exactly 26 signed events across all journeys; a failed consumer cannot
  lose canonical state (every row preserved, bounded retry state, no delivery
  recorded); retry after backoff dispatches every legitimate event exactly once
  (delivery ledger == consumer applications == 26, second pass duplicates
  nothing); a tampered envelope dead-letters with OUTBOX_ENVELOPE_TAMPERED, is
  re-queued by retryDeadLetter, rejected again on re-dispatch, never delivers,
  and repairState() exposes the bounded dead-letter row; append outside a
  transaction and unmapped EDD statuses fail closed (OUTBOX_APPEND_REQUIRES_TRANSACTION
  / EDD_STATUS_UNKNOWN).
- Authority outage / offline policy: adverse EDD truth (license unusable) denies
  refresh with a signed EDD_LICENSE_UNUSABLE recovery-only refusal and a durable
  lease_superseded outbox event; with EDD truth fully unreachable, a new lease
  cannot be issued (EDD_LICENSE_UNUSABLE; lease count unchanged — no outage or
  rollback creates a new local license); the existing signed lease remains the
  sole offline authority — verifyEnvelope returns active inside expiry,
  offline_grace inside expiry+grace, and EXPIRED past grace; the signed outage
  refusal still verifies (recovery remains available).
- Refresh credentials: a lease without an issued credential fails closed
  (REFRESH_CREDENTIAL_REQUIRED), a wrong credential is denied with a signed
  REFRESH_CREDENTIAL_INVALID recovery-only refusal without settling the lease,
  an unknown node fails closed (LEASE_NOT_FOUND), caller-controlled grant fields
  and unknown product codes on issuance fail closed (CALLER_CONTROLLED_GRANT_DENIED
  / PRODUCT_MAPPING_REQUIRED), and a forged refusal envelope fails closed
  (INVALID_SIGNATURE).
- Rollback is preservation-only: preserveForRollback journals schema events on
  the lifecycle, outbox, reconciliation, refresh, node, and account schemas and
  deletes nothing; EDD customer/order/license truth (including the refunded/
  revoked/expired rows), lifecycle journals, outbox rows and delivery ledgers,
  leases, nodes, refresh credentials, and the lease-schema migration journal are
  preserved; refund and revoke projections are never rolled back.
- Redaction: no raw email, payment/signing secret, EDD key material, or
  plaintext refresh credential appears anywhere in outbox/lifecycle/lease/
  refresh/reconciliation storage or in the harness output.
