# Third-Party Notices

Focusa ships with code from a number of open-source projects. This document is generated from the project's software bill of materials (SBOM) and must accompany any distribution.

This file is a **template**. The installer script regenerates the per-release copy at `/usr/local/share/focusa/licenses/` at install time. A CI-generated copy is also published with every GitHub release artifact.

## Categories

1. **Rust crates** — see `deny.toml` allow-list (MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, Unicode-DFS-2016, Unicode-3.0, Zlib, OpenSSL, CC0-1.0, MPL-2.0, 0BSD, BSL-1.1). Run `cargo deny check licenses` to regenerate.
2. **Node modules (apps/menubar)** — see `apps/menubar/THIRD_PARTY_NOTICES.md` (generated by `npx license-checker --production --csv`).
3. **macOS / iOS frameworks** — used under their respective Apple developer terms.
4. **Open-source pairable transports** — see "Open-Source Pairable Transports" section below.

## Open-Source Pairable Transports

When an operator enables a pairable tunnel, the installer downloads the binary at runtime and records that vendor's `LICENSE` and `NOTICE` files under `/usr/local/share/focusa/licenses/<vendor>/`. Self-hostable defaults (no third-party coordination server required):

| Transport | License | Repository | Self-hostable |
|---|---|---|---|
| `frp` (Fast Reverse Proxy) | Apache-2.0 | https://github.com/fatedier/frp | yes |
| `bore` | MIT | https://github.com/ekzhang/bore | yes |

Vendor interop transports (opt-in via `FOCUSA_TUNNEL_*=1`, vendor coordination server required):

| Transport | License | Repository | Coordination server |
|---|---|---|---|
| `cloudflared` | Apache-2.0 | https://github.com/cloudflare/cloudflared | Cloudflare |
| Tailscale client (`tailscale`) | BSD-3-Clause | https://github.com/tailscale/tailscale | Tailscale |
| `ngrok` | BSD-3-Clause (client) | https://github.com/ngrok/ngrok | ngrok |

`localhost.run` is **not supported** (unclear license, single-operator SSH relay).

## Generating per-release notices

```bash
# Rust SBOM
cargo install cargo-deny --locked
cargo deny check licenses > THIRD_PARTY_NOTICES.md

# npm SBOM (apps/menubar)
cd apps/menubar
npm install --no-save license-checker
npx license-checker --production --csv > THIRD_PARTY_NOTICES.md

# Tunnel vendor attributions
mkdir -p licenses/{frp,bore,cloudflared,tailscale,ngrok}
# Each installer step fetches the upstream LICENSE/NOTICE into its respective dir.
```

CI must regenerate these on every tagged release.
